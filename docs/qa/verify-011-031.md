## Findings
- **F1 (low, spec vs. code):** POST without an Origin header is accepted. If "every POST must carry a same-origin Origin" is the intended rule, `sameOrigin()` must drop the `!origin` clause, which breaks `team.js`/hooks callers unless they send `Origin: http://127.0.0.1:<port>`. Otherwise document it as intended and add a test for the missing-Origin case.
- **F2 (low):** `POST /api/settings {}` returns 200 `{ok:true, lang:null}` and removes `lang` from `settings.json` (copy went `{lang:"ko",ver:5}` -> `{ver:6}`). An empty body should be a 400, not a settings wipe. I restored the copy's file by hand.
- **F3 (nit):** a JSON array body (`[1]`) passes `readBody` (typeof object) and ends as a handler error (404 `unknown_project`) instead of 400 `bad_json`.
